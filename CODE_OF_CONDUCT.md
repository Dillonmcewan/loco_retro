# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**. The full text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Report unacceptable behavior by contacting the maintainer **[@dillonmcewan](https://github.com/dillonmcewan)** on GitHub (private message, or open a private security advisory at https://github.com/dillonmcewan/loco_retro/security/advisories/new for sensitive reports). All reports will be reviewed and investigated promptly and fairly. The maintainer is obligated to respect the privacy and security of the reporter of any incident.
